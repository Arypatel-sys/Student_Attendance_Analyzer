# Student Attendance Analyzer

## Overview

Student Attendance Analyzer is a Python project used to store student
attendance details and calculate attendance percentage.

The project also generates an attendance report and shows whether a
student is eligible or has attendance shortage.

## Features

1. Add Student
2. View Students
3. Calculate Attendance
4. Attendance Report
5. Input Validation
6. Testing

## Technologies Used

- Python
- Lists
- Functions
- Modules
- If-Else Statements
- For Loop
- Input and Output

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the main program using:

   python main.py

4. Select an option from the menu.

## Attendance Formula

Attendance Percentage = (Attended Classes / Total Classes) * 100

## Attendance Status

- 75% or above - Eligible
- Below 75% - Shortage
