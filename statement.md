# Student Attendance Analyzer

## Problem Statement

Maintaining student attendance manually can be time-consuming and
may lead to mistakes while calculating attendance percentage.

The Student Attendance Analyzer is developed to store student attendance
details and calculate attendance percentage in a simple way.

## Scope of the Project

The project allows the user to:

- Add student details
- View student details
- Calculate attendance percentage
- Generate attendance report
- Check attendance eligibility
- Validate class attendance details

## Target Users

The main target users of this project are:

- Students
- Teachers
- Faculty members

## High-Level Features

1. Add Student
2. View Students
3. Calculate Attendance
4. Attendance Report
5. Attendance Validation
6. Testing
